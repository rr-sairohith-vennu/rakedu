## Adding a New ADR

Only add an ADR here if the decision governs **all** products in this repository
equally. If scoped to a single product, add it to that product's
`spec/arch-decisions/` instead.

1. Create `ADR-NNN-short-title.md` in this directory
2. Fill in Context, Decision, and Consequences sections
3. Add a row to the table above
